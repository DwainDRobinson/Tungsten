# Tungsten

The monolithic repository for Puzzle Perks and all the services that supports the CRM and the Puzzle Perks Mobile Application.

## Features

### User Management:

- Authorization
- Authentication
- Manager user details

### Taxonomy Management:

- Tags

### Rewards Management:

- Tasks
- Points
- Rewards

### Content Management:

- Vidoes
- Songs
- Images
- Documents

### System Settings:

- Settings update system-wide
